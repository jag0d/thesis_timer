# Thesis Timer (`thesis_timer.sh`)

A simple, persistent stopwatch script for Bash designed to track time spent working on a thesis or project across multiple sessions.

The script is a one-shot generated by Gemini 3.8 Flash (via Antigravity CLI).

---

## Features

- **Persistent Stopwatch:** Automatically saves accumulated work time to `thesis_time.txt` upon exit and resumes from that value when launched again.
- **Reset Option:** Easily start from zero whenever needed by passing the `zero` argument.
- **Real-Time Display:** Live terminal display showing both total accumulated time and current session time with zero time drift.
- **EOF Stop:** Stops immediately when `CTRL+D` (EOF) is pressed.
- **Safe & Robust:**
  - Uses the system clock (`date +%s`) to avoid timing drift.
  - Automatically saves on exit and autosaves every 5 minutes (300 seconds) to prevent data loss.
  - Signal traps (`SIGINT`, `SIGTERM`, `SIGHUP`) ensure data is preserved and terminal settings (cursor, echo) are restored even if interrupted.
  - Atomic file writes prevent corrupted save files.
  - Directory-agnostic: can be executed from any current working directory.

---

## Installation & Setup

Make sure the script is executable:

```bash
chmod +x thesis_timer.sh
```

---

## Usage

### 1. Normal Mode (Resume)
Run without any arguments to resume from the previously accumulated time (or starts from `00:00:00` on the first run):

```bash
./thesis_timer.sh
```

### 2. Reset Mode (Start from 0)
To reset the stopwatch and start fresh from zero:

```bash
./thesis_timer.sh zero
```

### 3. Stopping the Stopwatch
Press **`CTRL+D`** (EOF) in the terminal at any time. The script will stop counting, save the final accumulated time into `thesis_time.txt`, and print a summary:

```text
--------------------------------------------------
 Stopwatch stopped.
 Session time:           01:15:30 (1h 15m 30s)
 Total accumulated time: 24:32:15 (1d 0h 32m 15s)
 Saved to:               /path/to/thesis_timer/thesis_time.txt
==================================================
```

---

## Storage File Format (`thesis_time.txt`)

The timing data is stored in `thesis_time.txt` in the same directory as the script. It uses a clean, human-readable format that is easily parsed by scripts and editable by humans:

```ini
# Thesis Stopwatch - Accumulated Time
# This file is automatically loaded and updated by thesis_timer.sh.
TOTAL_SECONDS=88335
FORMATTED=1d 00:32:15 (1d 0h 32m 15s (24h 32m 15s total))
LAST_UPDATED=2026-11-08 18:50:00
```

> **Manual adjustment:** If you ever need to manually adjust your accumulated time (e.g., adding time worked elsewhere), you can simply edit the `TOTAL_SECONDS=<number>` line in `thesis_time.txt` (or even write just a single raw number to the file).
